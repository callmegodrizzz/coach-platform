# Планер

Персональное приложение для расписания, домашки и личных задач. Один пользователь,
всё офлайн, без сервера и без аккаунтов.

## Что внутри

**Три вкладки:**

| Вкладка | Что делает |
|---|---|
| **Расписание** | Строка предметов со счётчиками → тап открывает предмет. Полоска недели с пометкой лекционная/семинарская. Карточки пар: время, тип, аудитория, преподаватель, и прямо под парой — открытая домашка по этому предмету. Ниже — задачи, запланированные на выбранный день. |
| **Дедлайны** | Вся домашка, сгруппированная: Просрочено → Сегодня → Завтра → На этой неделе → Позже → Без срока. Фильтр по предмету, кольцо прогресса. |
| **Планы** | Личные задачи, не связанные с учёбой. Здесь же кнопка выгрузки резервной копии. |

**Экран предмета** — цветная шапка, преподаватель, следующая пара, вся домашка,
свёрнутый блок выполненного.

**Добавление задачи** — FAB или «Задание по предмету» на карточке пары. При открытии
с карточки пары предмет уже выбран, а дедлайн подставлен на следующую пару по этому
предмету. Выбор предмета в форме тоже сам предлагает дедлайн.

**У задачи два поля даты:** «Сдать» (дедлайн) и «Делать» (когда ты собираешься этим
заняться). В план дня попадает «Делать», а если его нет — «Сдать». Без этого разделения
экран дня либо пустой, либо заваленный в день сдачи.

**Жесты:** свайп вправо — готово, свайп влево — перенести на завтра. Оба действия
с haptic-подтверждением за порогом.

## Расписание

Твоё расписание захардкожено в `src/data/schedule.ts` — экрана настроек нет намеренно.
Там же предметы, сетка звонков и чередование недель.

Группа 2-ТЛ, подгруппы: английский **E16**, немецкий **D24**.

Недели чередуются от якоря `ANCHOR_MONDAY = 2026-08-31` (лекционная).
Приложение считает чётность само.

> **Требует проверки:** семинарская неделя заполнена по допущению — та же сетка дней
> и пар, что на лекционной, отличаются только тип пары и аудитория ОЭП (207 вместо 26).
> Второе фото расписания было обрезано, дни недели на нём не читались.
> Проверить и поправить: `LESSONS` в `src/data/schedule.ts`, строки с `weeks: 'seminars'`.

## Уведомления

Два типа:

1. **За час до первой пары дня** — «Через час — ТВМС. 09:50 · Лекция · ауд. 26.»
2. **Каждый день в 17:00** — сводка по невыполненной домашке.

iOS хранит максимум 64 запланированных локальных уведомления, поэтому приложение
планирует окно на 14 дней вперёд и полностью пересобирает расписание уведомлений
при запуске, возврате из фона и после правки задач (`src/lib/notifications.ts`).

## Данные

Всё в `AsyncStorage` одним JSON-ом через `zustand/persist` (`src/lib/store.ts`).
Никакой БД и миграций — при десятке задач в неделю это лишняя сложность.

Резервная копия: вкладка «Планы» → иконка выгрузки → сохранить JSON в Файлы.

## Запуск на iPhone без платного Apple Developer

Нужен Mac с Xcode. Приложение подписывается бесплатным Apple ID и работает
полностью автономно, но **сертификат живёт 7 дней** — раз в неделю надо
переустановить. Данные при переустановке поверх сохраняются.

```bash
cd study-planner
npm install
npx expo prebuild --platform ios   # один раз
npx expo run:ios --device          # выбрать свой iPhone
```

При первом запуске Xcode попросит выбрать Team — укажи свой личный Apple ID
(Xcode → Settings → Accounts). На телефоне: Настройки → Основные → VPN и управление
устройством → доверять разработчику.

Дальше раз в неделю достаточно повторить `npx expo run:ios --device`.

Альтернативы, если недельная переустановка надоест: Apple Developer Program
($99/год, сборка живёт год + становятся доступны виджеты) или AltStore/SideStore
(переподписывает по Wi-Fi автоматически).
